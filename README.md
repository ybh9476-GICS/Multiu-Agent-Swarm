# Multi-Agent Swarm Orchestrator

슈퍼바이저와 하위 에이전트의 연결 및 정보 흐름을 보여주는 웹 목업입니다. IMPIX AI의 공개 정적 사이트를 로컬로 가져와 메뉴와 정보 표시 형식을 참고했습니다. 현재 상태, 진행률, 챗봇 답변은 시연용 데이터이며 실제 에이전트와 연결되어 있지 않습니다.

## 실행

Node.js 18 이상이 필요합니다. 프로젝트 폴더에서 다음 명령을 실행한 뒤 `http://127.0.0.1:18745/`를 여세요.

```bash
npm run dev
```

## 기본 조작

- 에이전트 타일: 마우스를 올리면 정보가 펼쳐지고 벗어나면 접힙니다. 클릭하면 펼친 상태가 유지되며 다시 클릭하면 접힙니다. 드래그로 위치를 옮길 수 있습니다. 회색 4단계 타일은 비활성 시안입니다.
- 화면: 마우스 휠이나 왼쪽 중앙 조절기로 그래프를 확대·축소하고, 빈 곳을 드래그해 이동합니다. 왼쪽 아래 버튼은 초기 배치를 복원합니다.
- 네비게이션: 오른쪽 아래 버튼으로 축소 지도를 열어 클릭·드래그로 화면을 이동합니다. 화면을 확대하거나 이동할 때도 잠시 자동으로 나타납니다.
- 캐릭터: 처음에는 숨겨져 있습니다. 오른쪽 아래 ‘캐릭터 보기’나 빈 곳 더블클릭으로 표시하고, 클릭하면 시연용 챗봇이 열립니다. 드래그로 위치를 옮길 수 있습니다.
- 오른쪽 아래 도움말 버튼에서 조작법을 다시 볼 수 있습니다.

별도의 IMPIX AI 정적 사이트 복제본은 [`impix-local/`](impix-local/README.md)에 있으며 그래프와 독립적으로 실행됩니다. 테스트는 `npm test`로 실행할 수 있습니다.
